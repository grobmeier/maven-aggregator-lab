# Acceptance case reference

Generated by `./acceptance-suite.sh reference`. Do not edit this file manually.

Use `./acceptance-suite.sh show CASE` to inspect evidence and execution details.

Sets: `all`, `ordering`, `failure`, `selection`, `inheritance`, `site`, `smoke`.
The smoke set covers sequential, concurrent, and standalone ordering.

## Ordering

| Case | Purpose | Policy |
|---|---|---|
| `seq-package` | Observe root package aggregation before child contributions. | `observation` |
| `concurrent-package` | Change only the builder from seq-package. Check actual timing. | `observation` |
| `seq-after-all` | Change only the binding from seq-package. Check the missing child barrier. | `ordered` |
| `concurrent-after-all` | Change only the builder from seq-after-all. Check the child barrier. | `ordered` |
| `legacy-parallel-after-all` | Check the legacy multithreaded builder with an explicit after:all binding. | `ordered` |
| `concurrent-after-all-t2` | Change only the builder from legacy-parallel-after-all. Keep two workers and after:all. | `ordered` |
| `single-seq` | Check exactly one start and end in a single-project sequential build. | `ordered` |
| `single-concurrent` | Change only the builder from single-seq. | `ordered` |
| `verify-success` | Check normal aggregation after package outputs and verification. | `ordered` |

## Failure

| Case | Purpose | Policy |
|---|---|---|
| `failure-fast` | Fail contributor a. Distinguish cleanup and attempted aggregation from success. | `failure_safety` |
| `failure-end` | Change only the failure policy from failure-fast. Check independent contributor b. | `failure_safety` |
| `failure-after-output` | Fail verification after contributions exist. Check whether after:all still creates a ZIP. | `success_only` |
